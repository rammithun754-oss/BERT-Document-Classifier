# 📄 BERT Document Classifier

A document classification system built using BERT and Hugging Face Transformers.

The model classifies documents into:

- AI
- Finance
- Education

This project demonstrates how to fine-tune a pre-trained BERT model for NLP classification tasks.

---

# 🚀 Features

✅ BERT Fine-Tuning

✅ Hugging Face Transformers

✅ Document Classification

✅ Transfer Learning

✅ Text Encoding

✅ CLS Token Classification

✅ Multi-Class Prediction
